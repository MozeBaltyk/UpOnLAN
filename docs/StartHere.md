# Start Here

Use this map to follow the existing documentation in a practical order. In the webapp, documentation folders become navigation groups.

1. **Getting started:** begin with [Getting Started](01-GettingStarted.md), manage [assets](Assets.md), and learn [iPXE](iPXE.md), [menu scripting](iPXE/Menu%20Scripting.md), and [ROM builds](iPXE/ROM%20Build.md).
2. **Understand PXE:** learn the [PXE basics](02-PXEBootBasics.md), then review [networking](Networks.md) and [DHCP](Networks/DHCP.md).
3. **Deploy securely:** follow [Deployment](UpOnLAN/Deployment.md).
4. **Troubleshoot and operate:** use [Operations](UpOnLAN/Operations.md) and [Troubleshoot](UpOnLAN/Troubleshoot.md); return to [Networking](Networks.md) and [DHCP](Networks/DHCP.md) for boot-path issues.
5. **Develop and contribute:** read [UpOnLAN development](UpOnLAN/Developpement.md) and [Contribute](UpOnLAN/Contribute.md).
